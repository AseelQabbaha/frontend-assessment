# Team Directory - Frontend Assessment

A modern, responsive Team Directory application built with Next.js, TypeScript, Material-UI, and TanStack Table.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000/en/team-directory](http://localhost:3000/en/team-directory)

## ✨ Features

- ✅ Pagination, Search, Filtering, Sorting
- ✅ Table View & Grid View
- ✅ English & Arabic (RTL) support
- ✅ Responsive Design
- ✅ Material-UI components
- ✅ Loading states & Error handling

## 📁 Project Structure

```
my-app/
├── app/[locale]/team-directory/  # Main page
├── components/                    # UI components
├── hooks/                        # Custom hooks
├── stores/                       # Zustand store
├── data/                         # Mock data
└── lib/                          # Utilities
```

## 🛠 Tech Stack

- Next.js 16, React 19, TypeScript
- Material-UI, TanStack Table
- Zustand, next-intl
- Tailwind CSS
